## 3. 取れなかった理由

1. 人間がログインしたタブは、自動操作側のタブグループの外にあり操作できなかった。このため、自動操作側のタブで人間にログインし直してもらった。
2. そのタブが背面（`document.visibilityState` が `hidden`、`hasFocus` が false）になり、背面では描画やタイマーが間引かれて測定値が実際より大きくなる恐れがあるため、計測を止めた。
3. 前面に出してもらい、`visible` を確認して計測を再開したが、1往復目の直後に再び `hidden` になった。人間のターミナル操作でChromeが背面に回ったと推測している（原因は未確認）。
4. 2〜5往復目は全て破棄。以降の計測は、人間判断により打ち切った。

背面での試走では、スクリプトが遅れながら画面遷移（部活を探す／人を探す／メッセージ／通知）を進めた。値は破棄し、表には使っていない。

## 4. 改善後の再計測に向けて

- 同じ条件（このMac・Chrome最新・現在の回線）で、Chromeのウィンドウを最前面にし、計測が終わるまで他の操作で隠さない。画面スリープもさせない。
- 計測開始前と計測中に `document.visibilityState === 'visible'` を確認する。`hidden` になった回は破棄し、注記する。
- 取得値は n=1 のため、改善前後の比較をする場合は、改善前も5回以上取り直す必要がある。

## 付録A 計測手順

### A-1 事前準備
1. Chromeで本番URLを開き、人間が E001（一般社員）でログインする。管理画面の計測には E002 でのログインが別途必要。
2. 計測用タブを最前面にし、`document.visibilityState` が `visible` であることを確認する。
3. 各遷移の前にアプリを一度開き、ウォーム状態にする。コールドは別行で1回記録する。

### A-2 計測用スクリプト（ブラウザのページ内で実行する）
アプリは同一オリジンの iframe（title が `streamlitApp`）内で動くため、親ページのスクリプトから読める。

```js
window.__d = () => document.querySelector('iframe[title="streamlitApp"]').contentDocument;
window.__sleep = ms => new Promise(r => setTimeout(r, ms));
window.__h1 = () => [...__d().querySelectorAll('h1')].map(h => h.innerText).join('|');
window.__side = label => d => {
  const b = [...d.querySelectorAll('[data-testid="stSidebar"] button')]
    .find(b => b.innerText.trim().startsWith(label));
  if (!b) throw new Error('no ' + label);
  b.click();
};
window.__m = async (click, done, timeout = 20000) => {
  const t0 = performance.now();
  click(__d());
  let stable = 0;
  while (performance.now() - t0 < timeout) {
    if (document.visibilityState !== 'visible') return { ms: null, note: 'hidden' };
    await __sleep(4);
    const dd = __d();
    const running = !!dd.querySelector('[data-testid="stStatusWidget"]');
    if (!running && done(dd)) { stable++; if (stable >= 3) return { ms: Math.round(performance.now() - t0 - 12) }; }
    else stable = 0;
  }
  return { ms: null, note: 'timeout' };
};
window.__nav = async label => {
  const before = __h1();
  const r = await __m(__side(label), d => [...d.querySelectorAll('h1')].map(h => h.innerText).join('|') !== before);
  r.h1 = __h1();
  return r;
};
```

使い方の例（ホーム→部活を探す→ホームを5往復）:

```js
await __nav('ホーム');  // 起点をホームにそろえる
for (let i = 0; i < 5; i++) {
  console.log(await __nav('部活を探す')); await __sleep(1200);
  console.log(await __nav('ホーム'));     await __sleep(1200);
}
```

注意:
- 1回のスクリプト実行は、ブラウザ操作ツールの上限（約45秒）に収まるよう、1回あたり数往復までにする。
- 計測はクリック送信時点からのため、人間の実クリックの反応時間は含まれない。
- 検索の入力は、入力欄の値を変えてから、件数表示（部活:「N件の部活が見つかりました」）が更新された時点を終点にする。この手順は今回未実施。
